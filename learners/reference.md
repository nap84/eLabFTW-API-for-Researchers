## Glossary

API
: In short, an application programming interface (API) is a connection (or interface) between computers of software programs that allows them to communicate or interact. See also: https://dev.to/icornea/what-are-apis-a-beginners-guide-with-examples-4ok8

Python Package
: A minimum description: bundled code that may be reused across different projects. See also: https://coderivers.org/blog/what-is-a-python-package/#what-is-a-python-package

Command-line
: sometimes called terminal, console, bash, command-line interface (CLI), shell, etc. is a means of interacting with software via commands as opposed to the graphical user interface (GUI)
